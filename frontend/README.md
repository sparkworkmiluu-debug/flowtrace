# FlowTrace Frontend

FlowTrace User Interface for Anti-Money Laundering (AML) Graph Intelligence.

## Features
- Interactive Money Flow Graph Visualization (Network subgraphs)
- Real-time AML Risk Score (0-100)
- Rule-Based Baseline vs. FlowTrace XGBoost Comparison
- Compliance ROI Calculator (Analyst hours & money saved)
- XAI Natural Language Reasoning via Gemini API
- 3 Zero-Friction Pre-loaded Scenarios (Fan-out, Fan-in, Cyclic Layering)
